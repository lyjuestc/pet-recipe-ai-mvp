# Pet Recipe AI MVP Architecture

## Data Flow

User Pet Profile

↓

Local Nutrition Rules (FEDIAF inspired)

↓

Prompt Builder

↓

OpenRouter Model

↓

Recipe JSON

↓

Safety Validation

↓

UI Display

## Design Principles

1. Safety first
2. No medical diagnosis
3. Supplementary diet recommendation only
4. Local toxic food filtering before and after AI generation
